# 技能复盘记录（元数据通道）

> **服务对象**：项目管理技能本身（**不是**项目工作复盘——项目总结归 `reports\`）。
> **触发**：① 事件自动采集——任务卡重建 / STATE 恢复 / 指针断链 / 越界改文件等任何**恢复动作**发生时，随即记一行（无需等人发起）；② 人工复盘——项目收尾 / 定期复盘 / 使用中遇阻。
> **记录方式**：追加式，每轮四段、每段一句话（防膨胀）。
> **存储位置（元数据通道）**：全部事件追加写**工作区根 `REVIEWS.md`**——**不写 `reports\`、不登 INDEX**。标「建议提级」的条目由管理者人工摘录回**技能源包**统一处置；源包只收提纯后的通用改进（保持干净可分享）；改进落地时按 `references/change-control.md` §A 走流程并递增 `MANIFEST.md` 版本。
> **裁决者**：管理者（初始化时在 MAP 环境段登记）；暂缓项在「第 3 次复发」时自动翻案复审。
> **闭环**：阻碍 → 根因 → 建议 → 处置 → 落地（先改权威源 `references/` → 同步 `MANIFEST.md` 版本 → 跑 `scripts/gen_views.py` 重生成派生视图 → 跑 `scripts/validate_workspace.py` 自检）。
