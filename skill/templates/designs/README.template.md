# 设计资产研究验证区 · 路由表（`designs/`）

> **本表是设计区的唯一入口。** 主技能（`SKILL.md`）与管理区**只路由到本表**，
> **不逐项登记设计区内的文件** —— 设计区多一份文件，管理区**不需要**知道。
> **原则**：★ **管理区 → 工程区 = 完整路由**；**管理区 → 设计区 = 只到本表**（资产定位 ≠ 工作管理）。

## 地图（本区长什么样）

```
designs/                          ← 设计资产研究验证区（仍在管理区内）
├── README.md                     ← ★ 本表（设计区唯一入口）
├── SKELETON.html / SKELETON.md   ← 项目当前工程模型（结构 → DESIGN-ID 可追溯）
├── <设计卡名>.md                  ← ① 设计卡·详述（为什么这样设计）
├── <设计卡名>.blueprint.html      ← ① 设计卡·蓝图（给人看方向）
├── _assets/                      ← ② 设计过程资产（概念稿 / 设计稿 / 参考图）
├── _research/                    ← ③④ 研究资料 + 研究验证脚本
└── archives/                     ← 已归档的设计卡（详述 + 蓝图成对移入）
```

> ★ **`_assets/` 与 `_research/` 只在真有东西时才建**（不预先建空目录 —— 空目录会被判为残留）。
> ★ **子目录需要时再各自加 README**（如 `_research/README.md` 列该主题的文件）；**默认只维护本表**。
## 本区住什么（四类）

| 类 | 放这里 | 不是这里 |
|---|---|---|
| **① 设计卡** | `<卡名>.md`（详述）+ `<卡名>.blueprint.html`（蓝图）；**有 `DESIGN-ID`** | — |
| **② 设计过程资产** | `_assets/`：概念稿 / 设计稿 / 参考图（**不会被引擎引用、不会被打包**）| **最终美术 / 3D / 音频素材** ⇒ 工程区 |
| **③ 研究资料** | `_research/`：缺口分析 / 对照实验 / 阶段报告 | — |
| **④ 研究验证脚本** | `_research/<主题>/`：验证**某个假设成不成立** | **工程验证脚本**（验证正式实现合不合格）⇒ 工程区 |

> ★ **判据一句话**：**它会不会被【打包】或被【引擎/代码引用】？** 会 ⇒ 工程区；不会 ⇒ 本区。

## 骨架（不放本表）

`SKELETON.html` / `SKELETON.md` —— **项目当前工程模型**（总体架构 / 模块关系 / 数据与调用主路径 / 结构 ↔ `DESIGN-ID`）。
> 它是**模型**，不是本表；本表只回答「**该读哪个文件**」。

## 归档

`archives/` —— 走完流程的设计卡（详述 + 蓝图一起移，**不删除**）。见 `references/design.md` §4。

## 研究型任务的闭环（★ 本区最重要的一条用法）

1. **工程中发现需要研究** → 建**普通任务卡**，`DESIGN-ID` 填 **`先跳过`**（有编号、被索引追踪）；
2. **研究过程产出** → 放 `_research/`（报告 / 数据 / 验证脚本）；
3. **研究出结论** → 建**设计卡** → 把任务卡的 `DESIGN-ID` 从 `先跳过` 改成真实 `DSN-…`（**单向、可追溯**）；
4. **设计定稿** → 拆后续任务卡；`_research/` 里的材料**留档**（作为设计依据的证据，不删）。

> ★ **`先跳过` 不是「不做设计」，是「设计依据还没到位」。**
