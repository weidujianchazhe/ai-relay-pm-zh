# 历史册（History Ledger）

> **本目录不是协议正文。** `MANIFEST.md` 规定：**协议正文 = `references/*.md`（顶层）**，本目录是**子目录**，因此
> **不参与协议耦合**：不进入接手路径、不被 `gen_views` 的可发现性/正文校验覆盖、**不作为规则依据**。
>
> **它记录什么**：出现过的 bug、重大改动、被推翻的判断、以及「曾经踩过什么坑」。
> **它不记录什么**：规则本身。**规则必须在 `references/*.md` 里以无时态的形式陈述**（"必须 X（否则 Y）"）。
>
> ★ **铁律**：**任何规则都不得只存在于本目录。** 若某条历史里有可复用的约束，**必须把它提炼进正文协议或检查脚本**，
> 本目录只留「那次发生了什么」——**记录可以留，耦合不能留**。

| 文件 | 内容 |
|---|---|
| `version-history.md` | 各版本开版原因（v3.6.1 → v4.1.1），原 `version-boundaries.md` §8.5–§8.12 |
| `gate-debt-cleared.md` | 已清偿的自门禁债（D1–D6），原 `self-gate-debt.md` |

> **怎么用**：想知道「这个规则为什么会存在」时来查；**日常接手不需要读本目录**。
