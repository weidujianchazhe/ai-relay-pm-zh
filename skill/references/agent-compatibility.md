# Agent Compatibility — ai-relay-pm-zh

面向**不会自动加载技能文件**的 Agent（如 Claude Code、Cursor 等纯编辑器 Agent）。

本技能的触发条件与路由信息，需要被写进项目的 Agent 配置文件，否则 Agent 不知道它存在。

> 本技能的产出物**不依赖任何平台 API**：
> 它只要求 Agent 具备**本地文件读写**与**命令执行**能力。无此能力的环境不适用。

---

## 一、自检：是否已经登记

在项目根目录的 `CLAUDE.md`、`AGENTS.md` 或 `.agent/rules.md` 中搜索标记：

```
<!-- PROJECT_MGMT_SKILL -->
```

- **找到** → 已登记，**停止**，不要重复写入。
- **没找到** → 按第四节执行登记。

---

## 二、本技能的登记条目

| Skill | 触发关键词 | SKILL.md 路径 |
|---|---|---|
| ai-relay-pm-zh | 开工初始化、接手项目、存量接入、多 AI 协作、交接、审计、代码规范 | `{技能源包路径}/SKILL.md` |

`{技能源包路径}` 替换为本技能实际所在目录。**该路径同时是项目 `MAP.md` 里 `[技能源包路径]` 的值**——两者必须一致（这是功能约定，不是可选项）。

---

## 三、发现同类技能

扫描本技能**同级目录**下的其他 `*/SKILL.md`。对每一个：

1. 读前 5 行 frontmatter，取出 `name` 与 `description`；
2. 从 `description` 中截取 `TRIGGER when:` 与 `DO NOT TRIGGER` 之间的文本，作为触发关键词；
3. 每个技能加一行到登记表。

搜索路径（首个命中即为技能根目录）：

```
1. .agent/skills/   2. .claude/skills/   3. ~/.agent/skills/   4. ~/.claude/skills/
```

---

## 四、写入登记

> [!CAUTION]
> **修改用户的配置文件前必须征得同意。** 不要静默追加。

写入以下块：

```markdown
<!-- PROJECT_MGMT_SKILL -->
## 项目管理技能

当请求匹配下表时，先读对应 SKILL.md 再作答。

| Skill | 触发关键词 | SKILL.md 路径 |
|---|---|---|
| （由上一步扫描得到） | | |

本项目启用管理区协议：任务卡驱动接手、快照式状态、分层索引、审计锚点。
开工前读 SKILL.md，接入时读 LEGACY_ONBOARDING.md。
<!-- /PROJECT_MGMT_SKILL -->
```

- 标记已存在 → **替换**两个标记之间的内容。
- 无标记 → **追加**到文件末尾，前面留一个空行。
- 无配置文件 → **先确认**，再决定是否创建。

---

## 五、能力清单（不满足则本技能不适用）

| 能力 | 用途 | 缺失后果 |
|---|---|---|
| 读文件 | 读任务卡 / 记录 / 快照 | 无法接手 |
| 写文件 | 写记录 / 更新快照 / 改索引 | 协议退化为人手填表 |
| 列目录 / 按模式匹配 | 索引与归档核对 | `check_index.py` 不可用 |
| 执行命令 | 跑 `scripts/` 下门禁脚本 | 校验退化为人工目检 |
| 执行 `git`（可选） | 越界改动检查 | 该项检查不可用，其余不受影响 |

**只有前两项是硬性门槛。** 后三项缺失只影响对应检查项，不影响协议成立。
