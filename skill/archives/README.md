# archives/（归档）

> 只进不出：历史文件不可变、不可删除、不可覆盖。此目录保留，请勿删除。

## 归档内容

| 子目录/文件 | 来源 | 触发条件 |
|---|---|---|
| `reports/`（归档的交接文件） | reports/ 下的旧交接记录 | 篇数达到 MAP「reports 归档阈值」（默认 20）滚动归档 |
| `done/`（完成卡归档） | tasks/ 下的完成任务卡 | 完成型提交时移入（**不删卡**） |
| `INDEX_archived.md`（INDEX 归档文件） | INDEX.md 的历史行 | 初始化即创建；先追加并校验 hash，再 CAS 更新主文件；失败保留主文件并写 `CONFLICT_*.md` |

## 归档算法

1. 为本次提交生成唯一 EVENT-ID，读取热区与冷区的 revision/hash。
2. 将新行写入临时文件，校验 RAW-SHA256 与 NORMALIZED-SHA256 后原子替换冷区文件。
3. 仅在冷区写入成功且 revision 未变化时 CAS 更新 `INDEX.md`（热区）；超 N 行的旧行同步移入冷区，**移入不删除**。
4. 任一步失败：不归档任务卡、不更新完成状态，生成冲突文件并记录 REVIEWS；**提交门禁失败即阻塞完成**。
