# 定时任务规范（schedule\）

> 提醒 / 周期检查 / 定期汇报。**定时是平台能力**，实现靠各平台原生机制——本目录只放规范。

## 用途

| 类型 | 例子 | 关联 |
|---|---|---|
| 定时提醒 | 会议提醒、截止提醒 | — |
| 周期检查 | 每日/每周项目状态检查 | 与 MAP 规则段的「定期排查」开关联动（默认关；开启后由 `scripts/audit_all.py` 执行并留痕） |
| 定期汇报 | 日报/周报生成 | 见 `report\` |

## 约定

1. 定时任务触发时，在执行指令中明确声明「本次请求由定时任务 [任务名] 触发」
2. 周期检查遵守 MAP 规则段的「定期排查」开关：默认关，管理者开启后由 AI 定期执行
3. 定时产出的记录按现有协议沉淀（reports\ + INDEX + STATE），不另建体系
4. 不把定时实现写进技能——各平台用自身定时能力，产出对齐本协议即可
5. **平台没有定时能力** → 用 `scripts/new_local.py` 生成本项目专属脚本，交给系统计划任务（Windows 计划任务 / Linux cron）调用
