# 可视化规范（visualize\）

> **平台无关规范**：任何平台 AI 均可用确定性图表/图解表达结构关系（不依赖特定平台可视化方案）。
> **执行原则**：尽力分析 · 点到即止 · 资源节制 · 信息完整是底线。
> **不设能力分级**：不按能力分级要求；按 AI 自身能力最大化分析，同时控制 token/计算资源占用。

---

## 一、适用与路由

| 内容 | 呈现 |
|---|---|
| 趋势/占比/排行/分布/比较（精确数据） | 数据图表（ECharts 类） |
| 流程/机制/架构/关系/时间线/状态机 | 结构图解（HTML/SVG 类） |
| 原图证据（需指出位置/区域/路径） | 保持原图 + 标注 |
| 无法可靠画清 | 回退文字（不用不可复核的图片兜底） |

## 二、原则

1. **精确数据用图表**；结构关系用图解；无法可靠画清时回退文字
2. **静态优先**：能用静态图说明的不加交互；交互仅在操作能揭示新状态/因果/过程时启用
3. **数据可复核**：真实数字必须来自输入或核验结果，不编造；示例数据明确标注
4. **点到即止**：不追求过度精美/复杂动效，控制资源占用
5. **信息完整是底线**：坐标轴/单位/图例/口径说明不省略

## 三、边界

- 不承接海报/头像/写实插画/艺术创作
- 地图/地理轨迹/行政区划类禁用（改文字或非地图表达）
- 附件交付（PDF/PPT/Word/Excel/图片）用对应文件能力，不用 renderer 冒充
- 原图作为证据时保持原貌，不裁切关键上下文、不用示意图替代

## 四、执行节制（token/计算占用）

- 单个可视化 ≤ 300 行，复杂内容拆分
- 优先简单实现（纯 HTML/SVG/Canvas），外部库失败时有静态替代
- 评估输出长度：信息能说清即止，不做装饰性扩展
