# 报告生成规范（report\）

> 日报 / 周报取数与格式。按需生成，产出按现有协议沉淀。

## 一、取数来源

| 报告要素 | 来源 |
|---|---|
| 当前进展 | STATE（人读区 + 当前进展） |
| 今日/本周做了什么 | reports\（按日期范围） + INDEX（近期行） |
| 明细 | 对应 reports 文件（沿 INDEX 交接列） |
| 下一步/风险 | STATE 决策点 + 任务卡要点 |

## 二、格式（精简）

### 日报

```
日期 / 做了什么 / 结果 / 下一步 / 风险（一句话各一项）
```

### 周报

```
本周汇总（进度/完成项/决策） + 下周计划（任务卡） + 风险与待确认
```

## 三、约定

- 报告不复制交接全文，只做摘要（取数 + 汇总）
- 生成后登记 INDEX（`[完成]` 或 `[接力]`），必要时存 reports\
- 频率与触发：按管理者需求或 schedule\ 定时任务
