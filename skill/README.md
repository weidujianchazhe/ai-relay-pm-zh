## 〇、先回答一个问题：这事要用全套吗？

```
一个对话窗能做完、不跨会话、不需要多方同时写  →  **卡片模式**
      产物：一个工作卡文件（templates/CARD.md）。本技能其余部分不必读。

长周期但单线推进、不需要分工与审计            →  **轻量工作区**
      产物：工作区 + 任务卡 + 索引。

长期 / 重 / 多 AI / 需要交接与审计              →  **完整工作区**
      产物：全部。本文档余下部分即为此形态。
```

**先从最小形态起步，不够再升**（升级即扩集，历史不回写）。问句与完整判据见 `references/onboarding.md` §1。

> **只要其中一个能力？也行。** 项目地图 / 任务卡 / 设计卡 / 代码书写规范**各自都能单独使用**——
> 入口与最小文件集见 `MANIFEST.md` 的「子能力与最小集」（含"单独使用时哪些门禁会失效"的诚实清单）。

**一屏速查卡**：`references/cheatsheet.md` —— 接手三步 / 作业四条 / **提交项数（随形态）** / 绝不做五条 / 固定命令。

## 〇之二、包结构（按功能域分目录）

```
SKILL.md          入口：只做路由，回答"该读哪个文件"
MANIFEST.md       版本与清单的唯一落点；数值口径说明
references/       协议正文（权威源），一个功能域一个文件
scripts/          可执行门禁（确定性函数，退出码 0/1/2/3）；scripts/local/ 为项目自定义脚本
templates/        初始化骨架
config/           出厂默认值（真值在实例 MAP 规则段）
adapters/         按语言落地附录，不属技能正文
ci/               CI 接线样板（GitHub Actions 等），不属技能正文
tools/            可选工具规范（可视化/定时/报告），只放规范不放实现
BLUEPRINT.md + blueprint/   设计蓝图（分页；**给人看的展示面**，不承载协议）
examples/         范例库骨架（索引表 + 入库流程；**本体不随包分发**）
LEGACY_ONBOARDING.md  存量项目接入（轻量登记 + 渐进整理，不深挖历史）
archives/         归档说明
```

**接手路径只有一条**（任务卡 → 记录 ±1 → 快照/地图）——**索引不在接手路径内**。
`references/` 下的文件**按需拉动**，不整目录读。

**一屏看全貌**：`python scripts/overview.py <工作区根>`（视图，不是门禁）。


## 一、这个技能解决什么

| 问题 | 机制 |
|---|---|
| 换一个 AI 后接不上 | **任务卡驱动接手** + 指针链（卡「上次交接」→ 记录）；**索引用于全局判断，不在接手路径内** |
| 新接手者要读全部文档 | **路由表**：只读所需——**读多少由卡决定，不由文档总量决定** |
| 指令模糊、AI 走错任务 | 卡内含**涉及文件路径 + 上次交接指针**，精准到达不靠猜 |
| 交接文件啰嗦 | **最小交接 6+1 块**；不贴 diff、不复制代码 |
| 改动无法追溯 | **索引一行一条** + 指向完整记录 |
| 多 AI 同时写互相踩 | **单写者原则** + 认领 + 独立记录文件 + 冲突文件 |
| 文档越攒越大 | **快照式状态** + 分层索引（热区/冷区）+ 滚动归档 |
| 技能自身事务污染项目档案 | **元数据通道**（REVIEWS.md），项目档案只存工作记录 |
| 每个项目都要重写检查脚本 | **脚本随包分发**（`scripts/`）——不必重造轮子 |

> **名词速查**：**指针链**＝卡「上次交接」→ 记录 的引用链；**热区 / 冷区**＝索引的最近若干行 / 归档全量（移入不删除）；**元数据通道**＝技能自身留痕文件（`REVIEWS.md`）；**6+1 块**＝交接报告的最小结构（六段 ＋ 任务卡更新）。完整术语见 `references/glossary.md`。

## 一之二、它明确**不做**什么（诚实边界）

- **不拦「绕过脚本直接改文件」**——拦不住，改为**事后检测**（哈希漂移 + 冲突文件）；
- **不做实时监督**——只在提交时与定期核查时介入；
- **不做多文件事务**（无「全或无」）——半事务由 `closeout.py repair` **幂等补偿**收敛；
- **不做跨机器互斥**——前提是「一个工作区一份本地文件系统」。

## 二、快速开始（新项目）

> 首次建工作区约 **5 分钟**（脚本就位 + 填 MAP）；**存量项目**走 `LEGACY_ONBOARDING.md`。

```
① 确认工作区根 {WORKSPACE_ROOT}（用户选一次；管理目录由技能自动创建）
     先查重：该根下若已有本项目实例 → 归并/确认唯一正本，禁止另起
② 建工作区（不整包复制；按 references/artifacts.md §1「工作区文件清单」逐项建）
     实例化：config/defaults.yml → config.yml、templates/*.template.md → 去掉 .template
     原样复制：SKILL.md、MANIFEST.md、references/（协议正文）、scripts/（脚本）、
               archives/README.md、tools/README.md
     创建空目录：tasks\ reports\ archives\done\ archives\INDEX_archived.md
③ 填 MAP：替换占位符 + 确认规则段配置
     （索引热区行数 / STATE 字数上限 / reports 归档阈值 / 定期排查开关 / 协作模式）
④ 登记第一条任务卡（tasks\，按工作命名）
⑤ 告知参与 AI：「协同工作区在 {WORKSPACE_ROOT}\<项目名>\，先读 tasks\ 里对应的卡」
```

**存量项目（已开工、无管理结构）**：跳过 ②~④，读 `LEGACY_ONBOARDING.md` 执行接入
（轻量登记 + 渐进整理，**不深挖历史**）。

## 三、接手一项工作（三步）

```
① 读 tasks\<卡>.md                  —— 定位工作
② 沿卡「上次交接」读 reports\<一篇>  —— 不够用时才读
③ 需要全局判断时读 STATE.md / MAP.md —— 首次接手 / 跨模块 / 整体审视
```

读完即把增量**写回**卡（保证每篇记录最多被读一次），然后开工。

> **"两份文件"说的是读哪些，不是读多少。** 成本按**字符**量：卡 + 指针记录 ≤ `{{config:capacity.onboarding_max_chars}}`、
> 单卡 ≤ `{{config:capacity.card_max_chars}}`（跑 `overview.py` 看「接手包」一行）。
> **文件数恒定 ≠ 成本恒定**——读进来的东西会留在上下文里，跟着整场对话一起付费。

## 四、提交（closeout）

提交项数**随形态**（light＝三项：记录 / 卡 / 索引；standard·coordination＝四项＋快照），缺一不算提交，**失败即阻塞**：

```
① 交接报告 ② 任务卡 ③ 索引镜像写 ④ 快照字段级更新
```

提交前跑：`python scripts/check_closeout.py <工作区根>`

## 七、适用 / 不适用（先看这个）

**适合**：跨会话、跨 AI 的长期项目 · 需要交接留痕与事后审计 · 存量无管理结构项目的渐进接入 · Python 单栈（门禁最完整）。
**不适合**：单轮问答 / 代码片段生成 · 无本地文件或命令执行能力的环境（网页对话、移动端、API 裸调）· 一次性短任务。

**使用前提**：本地文件系统 + 命令/文件执行能力（能落盘目录、读写卡与记录）。

**按能力维度判定，不枚举平台名称**：具备上述能力的平台自动兼容；
**不依赖任何平台私有接口、技能系统或 API**。

**不适用**：无本地文件能力的场景（网页对话 / 移动端 / 纯对话 / API 裸调）。

命令按 `{SHELL}` 二选一使用（PowerShell / bash），不跨平台混用；路径分隔符随平台。

**协议核心不变量（核心 5 条；完整 7 条见 `references/change-control.md` §B）**

1. **记录指针链**：任务卡「上次交接」→ 记录「下一步」→ 索引 [接力] 行——上手成本恒定的承重墙。
2. **分层索引**：索引**热区**只保留最近若干行，**冷区**（归档文件）保有全量；行**移入不删除**。
3. **每篇记录最多被读一次**：读过即把增量**写回**任务卡（write-back）。
4. **档案只进不出**：`reports\` 与 `archives\` 下文件禁删禁移（唯一例外＝归档流程，且移后必须同步索引行指向）。
5. **数据诚实边界**：恢复不出的内容标「数据待补」，**禁止伪造**。
