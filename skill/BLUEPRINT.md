# 学习路径 · 从零到能作业

> **本文件是【学习路径】，只回答一件事：我该怎么一步步学会用它。** 读一次即可，之后不必再读。
> **细则以 `references/` 为准**（本文件是与它不一致时的**从属面**，不承载协议）。
> **页索引在文件末**（`blueprint/02~08` 是进阶阅读，按需翻）。

---

## 第 0 步 · 这是什么，给谁用（30 秒）

**它是一套「接手指南」的脚手架**：把项目的状态、决定、下一步**写在固定的几份文件里**，
让下一个人（或下一个 AI、或三周后的你）**只读那几份就能接着干**，不必从头听你讲一遍背景。

> **它不替你思考，也不替你写代码。** 它只保证：**该知道的没丢、该验的能验、该接的接得上。**
> **不绑定平台、不绑定语言、不依赖任何服务**：正文是 Markdown，门禁是 Python 标准库脚本。

## 第 1 步 · 我需要它吗（三个问题）

| 你的情况 | 需要吗 |
|---|---|
| 一个人、一次做完、不打算再回来 | ❌ **不需要** |
| 换人 / 换 AI / 隔几周回来，要重新讲一遍背景 | ✅ **需要**（指针链解决它）|
| 「我改好了」但没人能验证，或改坏了说不清 | ✅ **需要**（锚源 + 门禁解决它）|

## 第 2 步 · 选定存储位置（★ 先做这一步，别跳过）

**问用户一句话**：★ **「你想把这个项目放在哪个文件夹？」** 拿到路径后，按下表判断：

| 用户给的那个文件夹 | 怎么做 |
|---|---|
| ★ **里面已经有别的文件夹 / 文件** | **在该文件夹下新建一个空白子文件夹**（名字**请用户确认**，建议用项目名），**再把管理区与项目区放进这个新子文件夹** |
| ★ **本身就是空文件夹** | **直接在这个文件夹里展开管理区与项目区**，不必再建一层 |

> ★ **判据**：**管理区与项目区必须独占一层目录**——它们会和同级的陌生文件混在一起时，先建壳再放。
> ★ **不要让用户自己猜**：路径、壳名都由**用户确认**后才建；建完回报「项目区 = … / 管理区 = …」两个绝对路径。

## 第 3 步 · 最小上手（4 条命令）

```
① 建项目区 + 建管理区（默认同级、名 = <项目名>-管理区，位置见上一步）
   ★ **再按 `references/onboarding.md` §3 的清单展开骨架**（templates → tasks/ reports/ archives/ designs/ …）
     —— **这步不做，下一步会报「tasks/ 不存在」**。
   → 跑：python scripts/validate_workspace.py <管理区>
② 判形态：读 references/onboarding.md §1（命中即停，从严到宽）
③ 建第一张任务卡：python scripts/closeout.py <管理区> new-card --project <项目> --module <模块> --skip-design
④ 提交前跑门禁：python scripts/check_closeout.py <管理区>
```

> ★ **只做到这里就能开工。** 其余能力（设计卡 / 多语言 / 并发 / 审计）**按需再学**。

## 第 4 步 · 跑通一轮（建卡 → 作业 → 提交 → 归档）

```
建卡（上一步③）→ 作业 → 写交接记录：python scripts/closeout.py <管理区> new-record "<主题>" --ai <标识>
→ 填 6+1 块 → 跑 check_closeout 通过 → 建卡归档：python scripts/closeout.py <管理区> card-archive "<卡名>"
```

> ★ **三态输出**：`[通过]` / `[问题]` / `[待核]`，退出码 0/1/2/3 —— **门禁由退出码说话，不由读文档判断**。
